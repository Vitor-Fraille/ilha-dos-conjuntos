# Como colaborar

## Fluxo de trabalho

1. Escolha ou crie uma issue.
2. Crie uma branch a partir de `main`.
3. Faça commits pequenos e descritivos.
4. Execute `npm run build`.
5. Abra um pull request e solicite a revisão de outro integrante.

## Padrão de commits

- `feat:` nova funcionalidade ou atividade;
- `fix:` correção;
- `docs:` documentação ou diário de bordo;
- `test:` testes automatizados;
- `style:` ajuste exclusivamente visual;
- `refactor:` melhoria interna sem mudar o comportamento.

## Definição de pronto

- linguagem adequada para estudantes do 5º ano;
- funciona com mouse, toque e teclado;
- informa por texto, e não somente por cores;
- apresenta dica educativa após erros;
- não solicita dados pessoais dos estudantes;
- compila sem erros.
