# Identidade UNEMAT

Logotipos PNG originais do pacote de identidade visual fornecido pela equipe em 23/09/2026. Não foram redesenhados ou recoloridos.

- `unemat-colorido.png`: aplicação em fundo branco.
- `unemat-branco.png`: aplicação em fundo azul escuro.

Paleta da interface baseada nos pixels do logo: azul #153755, verde #33552C e amarelo #FFCC29. Os tons claros são adaptações para os cartões e a leitura na tela, não uma especificação de manual oficial.

O catálogo PDF apresenta Aller Italic, mas não inclui arquivos de fonte web ou licença de redistribuição. A interface usa Segoe UI, Arial e sans-serif; a tipografia oficial permanece intacta nas imagens dos logos.
